Creates a stop point at the given *position* with the given *color*. The given *position* must be in the range 0 to 1.

This method is provided for HTML `CanvasGradient <https://doc.qt.io/qt-6/qml-qtquick-canvasgradient.html>`_ compatibility. It is equivalent to :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasGradient.setColorAt`.
