Constructs an image pattern. Pattern will use *image*. Please note that *image* should usually have at least :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasPainter.ImageFlag.Repeat` flag set. Pattern start position position is (0, 0) and pattern size (100, 100). Pattern angle is 0.0 and tint color white (no tinting).
