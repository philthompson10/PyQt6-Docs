Creates an arc centered on *centerPoint* with the given *radius*, starting at an angle of *a0* radians and ending at *a1* radians. The arc spans the given *direction*. When *connection* is :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasPainter.PathConnection.NotConnected`, the previous path is closed and a new sub-path is started.
