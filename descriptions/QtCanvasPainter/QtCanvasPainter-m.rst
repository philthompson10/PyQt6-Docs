.. sip:module-description::
    :status: done
    :brief:  Support for hardware-accelerated 2D painting

The :sip:ref:`~PyQt6.QtCanvasPainter` module provides classes for
hardware-accelerated imperative 2D painting.  This painting API is available
for both :sip:ref:`~PyQt6.QtQuick` and :sip:ref:`~PyQt6.QtWidgets`, and can
also be used directly with :sip:ref:`~PyQt6.QtGui.QRhi`.
