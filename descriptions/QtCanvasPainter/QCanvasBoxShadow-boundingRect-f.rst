Returns the area covered by the shadow. This takes into account the shadow :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasBoxShadow.rect`, :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasBoxShadow.blur` and :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasBoxShadow.spread`. If you don't want to use :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasPainter.drawBoxShadow` helper method, this can be used to for e.g. adding correctly sized :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasPainter.rect` into the path.

.. seealso:: :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasBoxShadow.setRect`, :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasBoxShadow.setBlur`, :sip:ref:`~PyQt6.QtCanvasPainter.QCanvasBoxShadow.setSpread`.
