This enum defines how data decoded in a :sip:ref:`~PyQt6.QtCore.QRangeModel.dropMimeData` customization gets written to the model.

A :sip:ref:`~PyQt6.QtCore.QRangeModel.dropMimeData` customization can return a bool value instead, in which case ``false`` maps to the DontDrop value, and ``true`` to Automatic.

.. seealso:: :sip:ref:`~PyQt6.QtCore.QRangeModel.canDropMimeData`, :sip:ref:`~PyQt6.QtCore.QRangeModel.dropMimeData`.
