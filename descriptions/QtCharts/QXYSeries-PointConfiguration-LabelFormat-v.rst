This enum value can be used to set custom label text per-point. If used together with :sip:ref:`~PyQt6.QtCharts.QXYSeries.setPointConfiguration`, the configuration's value should be a string.

**Note:** If an empty string is set as the LabelFormat, it will be ignored, and the series :sip:ref:`~PyQt6.QtCharts.QXYSeries.pointLabelsFormat` will be used.
