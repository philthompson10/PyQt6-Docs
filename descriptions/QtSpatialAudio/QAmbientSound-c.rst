A stereo overlay sound.

:sip:ref:`~PyQt6.QtSpatialAudio.QAmbientSound` represents a position and orientation independent sound. It's commonly used for background sounds (e.g. music) that is supposed to be independent of the listeners position and orientation.

**Note:** :sip:ref:`~PyQt6.QtSpatialAudio.QAmbientSound` is only active when the :sip:ref:`~PyQt6.QtSpatialAudio.QAudioEngine` is using OutputMode::Stereo or OutputMode::Headphone.
