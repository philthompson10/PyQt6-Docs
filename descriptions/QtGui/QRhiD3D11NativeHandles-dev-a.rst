Points to a `ID3D11Device <https://learn.microsoft.com/en-us/windows/win32/api/d3d11/nn-d3d11-id3d11device>`_ or left set to ``nullptr`` if no existing device is to be imported.

**Note:** When importing a device, both the device and the device context must be set to valid objects.
