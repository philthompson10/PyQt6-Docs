Swapchain render target resource.

When targeting the color buffers of a swapchain, active render target is a :sip:ref:`~PyQt6.QtGui.QRhiSwapChainRenderTarget`. This is what :sip:ref:`~PyQt6.QtGui.QRhiSwapChain.currentFrameRenderTarget` returns.

**Note:** This is a RHI API with limited compatibility guarantees, see :sip:ref:`~PyQt6.QtGui.QRhi` for details.

.. seealso:: :sip:ref:`~PyQt6.QtGui.QRhiSwapChain`.
