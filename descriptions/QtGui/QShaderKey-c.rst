Specifies the shading language, the version with flags, and the variant.

A default constructed :sip:ref:`~PyQt6.QtGui.QShaderKey` has source set to SpirvShader and sourceVersion set to 100. sourceVariant defaults to StandardShader.

**Note:** This is a RHI API with limited compatibility guarantees, see :sip:ref:`~PyQt6.QtGui.QShader` for details.
