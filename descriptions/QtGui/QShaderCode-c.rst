Contains source or binary code for a shader and additional metadata.

When `shader() <https://doc.qt.io/qt-6/qml-qtquick3d-skymaterial.html#shader>`_ is empty after retrieving a :sip:ref:`~PyQt6.QtGui.QShaderCode` instance from :sip:ref:`~PyQt6.QtGui.QShader`, it indicates no shader code was found for the requested key.

**Note:** This is a RHI API with limited compatibility guarantees, see :sip:ref:`~PyQt6.QtGui.QShader` for details.
