Indicates that the color value of 1.0 is interpreted as the value of the SDR white. (which can be e.g. 200 nits, but will vary depending on screen brightness) This is the behavior of HDR-enabled windows on Apple platforms. See `this page <https://developer.apple.com/documentation/metal/hdr_content/displaying_hdr_content_in_a_metal_layer>`_ for more information on Apple's EDR system.
