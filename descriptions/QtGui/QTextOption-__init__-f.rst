Constructs a text option with default properties for text. The text alignment property is set to :sip:ref:`~PyQt6.QtCore.Qt.AlignmentFlag.AlignLeft`. The word wrap property is set to :sip:ref:`~PyQt6.QtGui.QTextOption.WrapMode.WordWrap`. The using of design metrics flag is set to false.

**Note:** Calling this constructor will set the default text direction to :sip:ref:`~PyQt6.QtCore.Qt.LayoutDirection.LayoutDirectionAuto`.
