Specifies the feature level passed to `D3D11CreateDevice() <https://learn.microsoft.com/en-us/windows/win32/api/d3d11/nf-d3d11-d3d11createdevice>`_. Relevant only when :sip:ref:`~PyQt6.QtGui.QRhi` creates the device, ignored when importing a device and device context. When not set, the default rules outlined in the D3D documentation apply.
