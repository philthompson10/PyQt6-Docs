Indirect draw buffer. This allows the :sip:ref:`~PyQt6.QtGui.QRhiBuffer` to be used in :sip:ref:`~PyQt6.QtGui.QRhiCommandBuffer.drawIndirect` and :sip:ref:`~PyQt6.QtGui.QRhiCommandBuffer.drawIndexedIndirect`. This usage can be combined with types Immutable or Static. Combining it with Dynamic is unsupported with D3D11, where create() will fail. This usage may also be combined with StorageBuffer on backends that support :sip:ref:`~PyQt6.QtGui.QRhi.Feature.Compute`, allowing indirect draw commands to be generated by compute shaders and consumed by indirect draw calls.
