Constructs a text option with the given *alignment* for text. The word wrap property is set to :sip:ref:`~PyQt6.QtGui.QTextOption.WrapMode.WordWrap`. The using of design metrics flag is set to false.

**Note:** Calling this constructor will set the default text direction to the current value of :sip:ref:`~PyQt6.QtGui.QGuiApplication.layoutDirection` which depends on the system locale. For backwards compatibility reasons, this does not match the default text direction set by the default constructor.
