Indicates that setting a PolygonMode other than the default Fill is supported for :sip:ref:`~PyQt6.QtGui.QRhiGraphicsPipeline`. A common use case for changing the mode to Line is to get wireframe rendering. This however is not available as a core OpenGL ES feature, and is optional with Vulkan as well as some mobile GPUs may not offer the feature.
