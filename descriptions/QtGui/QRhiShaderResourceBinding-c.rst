Describes the shader resource for a single binding point.

A :sip:ref:`~PyQt6.QtGui.QRhiShaderResourceBinding` cannot be constructed directly. Instead, use the static functions such as :sip:ref:`~PyQt6.QtGui.QRhiShaderResourceBinding.uniformBuffer` or :sip:ref:`~PyQt6.QtGui.QRhiShaderResourceBinding.sampledTexture` to get an instance.

**Note:** This is a RHI API with limited compatibility guarantees, see :sip:ref:`~PyQt6.QtGui.QRhi` for details.
